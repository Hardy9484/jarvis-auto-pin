Jarvis Auto Pin

Jarvis Auto Pin ist eine private Automatisierung von Markus (Betreiber, Kontakt siehe unten), die eigene kreative Werke (u. a. Print-on-Demand-Designs) über die Pinterest-API auf das eigene Pinterest-Konto pinnt. Die Anwendung wird ausschließlich persönlich und nicht-kommerziell für dieses eine Konto genutzt.

Jede Veröffentlichung wird vor dem Posten einzeln manuell bestätigt - es gibt keine vollautomatische Veröffentlichung ohne menschliche Freigabe.
